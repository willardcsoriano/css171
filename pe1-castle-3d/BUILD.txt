CSS171 PE1 - Rotating Textured 3D Castle (Willard Soriano)
=========================================================

Files
  CSS171_PE1_Soriano.cpp                source file
  textures/                             the six texture images the program
                                        loads (keep this folder next to the .cpp)
  third_party/glad/                     OpenGL 3.3 core loader (glad.c + headers)
  third_party/stb_image.h               image loader the source includes
  Makefile                              build script for Linux
  CSS171_PE1_Soriano_sample_output.mp4  sample output video

Requirements
  OpenGL 3.3, GLFW, GLM, GLAD (included) and stb_image (included).

Build and run on Linux (Debian/Ubuntu)
  sudo apt install g++ make libglfw3-dev libglm-dev
  make run

Build and run in Visual Studio
  Use the course's "Visual Studio and OpenGL Setup" (GLFW, GLAD, GLM).
  Add CSS171_PE1_Soriano.cpp to the project and keep textures/ and
  third_party/ next to it. If the project does not already compile its own
  glad.c, also add third_party/glad/src/glad.c and put
  third_party/glad/include on the include path. Build and run.

  The program loads textures/*.png relative to its working directory, so run
  it from the folder that contains textures/ (Visual Studio's default
  working directory is the project folder).

Controls
  ESC closes the window.
